# Accessibility review

Check:

- keyboard navigation
- focus states
- labels
- contrast
- semantic elements
- ARIA usage
- screen-reader issues

Prefer native elements over extra ARIA.

The storefront has an Accessibility page; do not contradict it with invented legal claims.

Fix confirmed, low-risk issues (missing labels, buttons that should be links, missing alt on meaningful images). Record contrast failures with the sampled colors.

## How to read the legend

- Green is extra image so the knife does not show white paper. It is not a printed frame.
- Blue is where the pouch art is trimmed in this flat. It is not a design rule.
- Red is a stand-in for construction. The proof itself calls it provisional.

## What “approved version” must contain later

When a supplier returns their prepress proof, file it here as `aura-pouch-proof-vN.pdf` plus a photo of the physical sample. Update `09-final-print-approval` with the version and the date. Do not overwrite V9. Keep it as the reference this package was transcribed from.

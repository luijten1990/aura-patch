# 08 — Print specifications

One sheet for the factory. Items marked **confirm** are not on the current proofs. Do not let prepress fill them in silently.

## Pouch

| Requirement | Specification |
| --- | --- |
| Product | Stand-up pouch for 30 daily wellness patches |
| Artwork reference | Footer-refined flat proof V9 |
| Flat panels | 130 x 160 mm each, as stated on the proof |
| Spread on that proof | 260 x 180 mm |
| Bleed | 5 mm outer, as stated on the proof |
| Dieline | **Confirm.** Official converter file required. Red rules on V9 are provisional |
| Print | **Confirm** surface or reverse print, and the film structure |
| Colour | CMYK builds to match the signed drawdown. No Pantone specified |
| White ink | **Confirm** if the laminate needs a white underprint |
| Finish | **Confirm** matte, gloss, or soft-touch. Not stated on V9 |
| Zipper | Resealable pouch is implied by “Reseal after use.” Placement **confirm** on the dieline. Keep ink and varnish off the seal track |
| Tear notch | **Confirm** with the converter. Do not guess from the mockup |
| Body copy | 8.5 pt, as retained on V9 |
| Guides | Green, blue, and red must not print |
| Barcode | Only the registered GTIN file. The V9 code is nominal |
| Variable text | Lot and expiry areas left open unless this run is coded |
| Proof | Supplier prepress proof, then a physical sample, before the production quantity |

## Sticker

| Requirement | Specification |
| --- | --- |
| Cut | 40 mm circle |
| Imposition | 6 up, 2 x 3, on an 86 x 128 mm sheet as drawn |
| Bleed | 3 mm |
| Safe | Wordmark and symbol inside the blue safe line |
| Colour | CMYK cream ground |
| Gold | **Confirm one:** cold foil, hot foil, or metallic gold ink |
| Spots | The print guide says no spot colours. Revise that line if a metallic ink is ordered |
| Resolution | 300 dpi for any raster; vector for type and the flower mark |
| Cut method | **Confirm** kiss-cut to liner |
| Stock and adhesive | **Confirm.** State whether the sticker contacts skin or only the patch release liner |

## File handoff

- PDF/X where the printer accepts it, fonts outlined or supplied, images 300 dpi, trim box equal to the dieline trim.
- Layers named: `ART`, `FOIL` (only if used), `DIELINE` (non-printing), `GUIDES` (non-printing).
- One PDF for the pouch, one PDF for the sticker. Do not send a marketing mockup as the only file.

## Batch consistency

The next order should match the signed drawdown, not a new screen grab. Record CMYK (and foil spec, if any) in `05-brand-guidelines` after the first approved physical sample so later batches have a number to hit.

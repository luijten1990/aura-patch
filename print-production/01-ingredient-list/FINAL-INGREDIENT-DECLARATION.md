# 01 — Ingredient declaration

Status: **final for the pouch and the website.** Confirmed 13 Nov 2026 (Asia/Bangkok). This replaces the earlier 19-name marketing list.

The storefront reads this same list from `auraCore.ingredients` in `apps/storefront/src/lib/data/aura-collection.ts`.

## Declaration

Stabilized Allicin (from Allium Sativum), Vitamin C (Ascorbic Acid), Vitamin B2 (Riboflavin), Broccoli Sprout Extract, BCAA+EAA blend (L-Leucine, L-Valine, L-Isoleucine, L-Lysine, L-Phenylalanine, L-Threonine, L-Methionine, L-Histidine, L-Tryptophan), Quercetin, Electrolytes (from Sodium Chloride), Ginger Extract, Zinc Picolinate, Hawthorn Berry Powder, Tea Tree Powder, Vitamin E (Mixed Tocopherols), Raspberry Ketones, Vitamin D3 (Cholecalciferol), Vitamin K2 (Menaquinone-7), Bacillus Subtilis, Bifidobacterium Longum, Lactobacillus Casei, Lactobacillus Paracasei, Lactobacillus Acidophilus, Vitamin A (Retinyl Palmitate).

Twenty-one named items. The BCAA+EAA blend is one item and contains nine amino acids.

## Printer instruction

- Set this text in the back-panel ingredients block only.
- Do not add disease, clinical, or immune-support claims into the ingredient line.
- Do not abbreviate or reorder after sign-off.
- Amounts per patch are not on Proof V9. If a market requires a quantitative declaration, supply that table before print. Do not estimate milligrams.

Regulatory review of the surrounding pouch copy is still required before a production run. See `09-final-print-approval`.

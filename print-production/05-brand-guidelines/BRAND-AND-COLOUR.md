# 05 — Brand and colour specification

Exact ink books are not on the proofs. Do not invent a Pantone match. Match the signed physical sample, then record the measured values in the empty table at the bottom.

## Marks

| Mark | Where it appears | File status |
| --- | --- | --- |
| Flower-of-life line symbol | Pouch front, pouch footer, sticker | Proof says logos were traced. Supply SVG, AI, or EPS from the master before print |
| AURA wordmark | Pouch front, sticker, pouch footer | Same. Outline or supply the font |
| Gold rule under the wordmark | Pouch front, sticker | Vector stroke in the print file |
| Peel / Apply / Go icons | Pouch back | Vector |
| Cruelty Free, Vegan, Paraben Free, No Fillers icons | Pouch front | Vector line icons |

Minimum: one vector master for the symbol and one for the wordmark, saved in `05-brand-guidelines/` as `aura-symbol.svg` and `aura-wordmark.svg` (AI or EPS acceptable alongside). The traced versions on Proof V9 are a placeholder.

## Fonts

The proof does not name the type family. It only keeps 8.5 pt body.

- Record the approved family and weight for the wordmark, headings, and body.
- Printer package must include the font files you are licensed to send, or all type converted to outlines.
- Do not substitute a lookalike on press.

## Colour roles

| Role | Visual target from current art | Process note |
| --- | --- | --- |
| Pouch ground | Deep teal / forest green | Build in CMYK for the laminate you will print. Record the build after the drawdown |
| Pouch gold | Yellow-gold line art and rules | Process build unless a metallic is specified for the pouch. The pouch proof does not call foil |
| Pouch type | Warm white / ivory | Knockout or white ink, depending on reverse or surface print. Confirm with the converter |
| Sticker ground | Soft cream | CMYK. No spot called on the sticker guide |
| Sticker gold | Gold foil effect **or** metallic gold ink | One process only. Foil needs a foil layer and a keep-out for fine detail. Metallic ink needs the ink maker’s drawdown |
| Guides | Green, blue, red | Non-printing layers |

The sticker guide states **CMYK, no spot colours**, and separately allows a gold foil effect. If you choose foil, that foil is a separate converting step. It is not a fifth process colour in the CMYK file. If you choose metallic gold ink, say so in the print spec. The “no spot” line on the guide then has to be revised so the printer is not given two instructions.

## Finish

| Piece | Specified today | Decide before order |
| --- | --- | --- |
| Pouch | Not stated on Proof V9 | Matte laminate, soft-touch, or gloss. Write the choice in `08-print-specifications` |
| Sticker face | Not stated | Matte or gloss face stock, plus foil or metallic ink |
| Varnish | Not stated | Spot gloss only if it does not sit under the zipper or seals |

# 03 — Patch sticker cutting specification

Source: *AURA PATCH — PRINT GUIDE*, round patch sticker, transcribed 13 Nov 2026 (Asia/Bangkok).

Reference image: `round-patch-sticker-print-guide-reference.png` in this folder. It is a layout guide, not the press PDF.

## Sheet

| Item | Specification |
| --- | --- |
| Product | Round patch sticker |
| Cut size | 40 mm diameter |
| Count | 6 stickers per sheet |
| Grid | 2 columns x 3 rows |
| Sheet trim shown | 86 mm wide x 128 mm high |
| Bleed | 3 mm past the cut line, around each sticker |
| Safe area | Inside the blue dashed line. Wordmark, rule, and flower mark stay inside it |
| Cut line | Red. 40 mm diameter. Non-printing on the live art |
| Colour mode | CMYK. No spot colours on this guide |
| File | High-resolution PDF, 300 dpi where raster is used. Prefer vector for the mark and type |
| Gold | “Gold foil effect (or metallic gold print)”. Choose one process in `08-print-specifications` before plating |
| Ground | Soft cream. Match the approved drawdown. No measured Lab value is on the guide |

## Artwork on each sticker

- Flower-of-life line mark
- Wordmark AURA
- Short gold rule under the wordmark
- No ingredient copy on the sticker

## Prepress notes already on the guide

- Keep all text and the logo inside the safe area.
- Extend artwork 3 mm beyond the cut.
- Supply high-resolution art so the foil or metallic edge stays sharp.
- Check colour against a printed proof, not the screen.

## Open items

- Gap between stickers and the sheet margin is not dimensioned beyond the overall 86 x 128 mm. Rebuild on the cutter’s template.
- Liner, adhesive (skin-contact safe if the sticker is applied to the patch backing), and face stock are not specified.
- Kiss-cut versus through-cut is not specified. Default expectation for a sheet of six is kiss-cut to the liner. Confirm with the converter.
- The 40 mm circle is the sticker, not a claim that the patch itself is 40 mm. Confirm the patch die separately.

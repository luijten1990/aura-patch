# Design system (observed)

Direction for Aura Patch storefront work. Do not invent a new palette.

Observed language:

- Forest / cream / wine / gold
- Display type on the wordmark; uppercase tracking on nav
- Rounded-full primary CTAs (`aura-button`) vs bordered purchase-type cards on product

Subscribe & Save vs one-time is an intentional difference. Do not collapse those treatments.
